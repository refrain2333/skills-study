## 方法

每条提示都发送给每个模型；技能描述的顺序按确定性方式打乱，每次重复的顺序不同。模型返回 JSON 技能排名。首位技能与人工标注的 `expected_primary_skill` 一致时计入 top-1；预期技能在前三位时计入 top-3。

智能体未加载任何技能（`settingSources: []`），唯一信号是提示词中的技能描述。置信区间为 2,000 次重采样的 95% 自助法区间。

## 复现

```bash
cd researcher/benchmarks/sdk-runner
npm install
export CURSOR_API_KEY=<你的密钥>
node --experimental-strip-types src/runRouter.ts --models claude-opus-4-7,composer-2,gemini-3.1-pro,gpt-5.5 --reps 3 --seed 1 --max-budget-usd 15
python3 researcher/scripts/render_router_report.py \
    --results researcher/benchmarks/router/results/<日期>-<种子> \
    --fixture researcher/benchmarks/router/prompts.jsonl \
    --output researcher/benchmarks/router/results-published/<日期>.md
```

每次运行的 JSON（提示、模型、重复次数、原始输出和解析排名）保存在同目录下被 Git 忽略的 `results/` 中。
