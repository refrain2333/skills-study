# 网页搜索工具

## 用途

搜索与主题相关的信息，返回结构化结果、摘要、网址和元数据。

## 输入

| 字段 | 类型 | 必需 | 说明 |
| --- | --- | --- | --- |
| `query` | string | 是 | 搜索查询；越具体，结果通常越好 |
| `maxResults` | number | 否 | 结果上限，默认 10，范围 1—20 |
| `filters.dateRange` | enum | 否 | 时间范围：day、week、month、year、any |
| `filters.sourceType` | enum | 否 | 优先来源类别：all、news、academic、documentation |
| `filters.excludeDomains` | string[] | 否 | 排除的网站域名 |

## 输出

返回成功状态、结果列表（标题、网址、摘要、来源域名、可选发布日期和相关度）、总结果数，以及查询、耗时和已用筛选条件等元数据。

## 查询优化

1. 使用明确术语。
2. 使用引号搜索精确短语。
3. 支持时使用 `site:`、`-term` 和 `OR` 等操作符。
4. 加入相关上下文词语。
5. 查询最新资料时加入年份。

## 实现建议

限制请求速率；缓存重复查询；筛除低质量来源；妥善处理 API 失败；按隐私规则记录查询。
