# LinkedIn 帖子模板

## 元数据

```yaml
topic: "[主题]"
pillar: "[内容支柱]"
format: "story|lesson|hot_take|how_to|list"
```

## 开头（前 2—3 行）

必须在读者点击“查看更多”之前就能吸引注意：

```text
[写一个让读者愿意继续阅读的开场]
```

## 正文

### 故事格式

```text
背景：
[情境或背景]

挑战：
[发生了什么或遇到了什么问题]

转折：
[什么发生了变化]

经验：
[学到了什么]
```

### 经验/教程格式

```text
以下是如何实现[目标]：

1. [步骤或要点]
[简要说明]

2. [步骤或要点]
[简要说明]

3. [步骤或要点]
[简要说明]

关键见解：
[填写]
```

### 观点格式

```text
[有争议但有依据的观点]

理由：
[支持理由一]
[支持理由二]
[限定条件或补充说明]
```

## 收尾

```text
[总结或邀请讨论]
```

## 互动问题

```text
[向读者提问]
例如：“你怎么看？”、“你遇到过这种情况吗？”、“你还会补充什么？”
```

## 话题标签

最多 3—5 个：`#[标签] #[标签] #[标签]`

## 发布前检查

- [ ] 前 2—3 行足够吸引人。
- [ ] 使用换行提升可读性。
- [ ] 内容专业但有人情味。
- [ ] 以互动问题结尾。
- [ ] 符合个人品牌；LinkedIn 风格可以稍正式。
- [ ] 没有过度自我推销。
