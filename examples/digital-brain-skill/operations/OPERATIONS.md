# 日常运营模块

个人效率管理系统。

## 模块文件

| 文件 | 格式 | 用途 |
| --- | --- | --- |
| `todos.md` | Markdown | 当前任务清单 |
| `goals.yaml` | YAML | OKR 和目标追踪 |
| `meetings.jsonl` | JSONL | 会议日志和笔记 |
| `metrics.jsonl` | JSONL | 关键指标记录 |
| `reviews/` | 目录 | 周度和月度回顾 |

## 工作流

### 每日流程

```text
1. 早上：查看 todos.md 并排序。
2. 白天：勾选已完成事项，并记录新任务。
3. 晚上：记录会议并更新指标。
```

### 周度回顾（每周日）

1. 运行 `agents/scripts/weekly_review.py`。
2. 对比已完成事项和原计划。
3. 检查 `metrics.jsonl` 中的指标。
4. 规划下周优先事项。
5. 更新 `goals.yaml` 中的进度。

### 季度目标设定

1. 回顾上一季度的目标。
2. 在 `goals.yaml` 中更新新 OKR。
3. 拆解为月度目标。
4. 让内容日历与目标保持一致。

## 智能体指引

<instructions>
管理日常运营时：
1. **待办**：使用 P0—P3 优先级并保持清单最新。
2. **目标**：作重大决策或规划前查看目标。
3. **会议**：会后立即记录关键收获。
4. **指标**：至少每周更新一次。
5. **回顾**：提炼洞见，不要只罗列摘要。

优先级：
- P0：今天完成，会阻塞其他工作。
- P1：本周完成，重要。
- P2：本月完成，有价值。
- P3：待办事项，有余力时处理。

用户要求规划或排序时：
1. 检查当前 goals.yaml 是否匹配。
2. 查看 todos.md 的现有容量。
3. 考虑时效性和依赖关系。
4. 提出可行时间表。
</instructions>

## 效率原则

```yaml
principles:
  - "优先处理重要工作，减少忙而无效"
  - "P1—P3 任务先完成，再追求完美"
  - "批量处理相似任务"
  - "保护深度工作时间"
  - "周度回顾必须坚持"
```
