# 兼容 Anthropic API

> 使用 Anthropic SDK 调用 MiniMax 模型。

为满足开发者对 Anthropic API 生态的需求，MiniMax API 支持 Anthropic API 格式。完成简单配置后，即可在 Anthropic SDK 中调用 MiniMax 模型。

## 快速开始

### 1. 安装 SDK

```bash
pip install anthropic
```

或：

```bash
npm install @anthropic-ai/sdk
```

### 2. 设置环境变量

国际用户使用 `https://api.minimax.io/anthropic`；中国大陆用户使用 `https://api.minimaxi.com/anthropic`。

```bash
export ANTHROPIC_BASE_URL=https://api.minimax.io/anthropic
export ANTHROPIC_API_KEY=${YOUR_API_KEY}
```

### 3. 调用 API

```python
import anthropic

client = anthropic.Anthropic()
message = client.messages.create(
    model="MiniMax-M2.1",
    max_tokens=1000,
    system="你是一名乐于助人的助手。",
    messages=[{
        "role": "user",
        "content": [{"type": "text", "text": "你好，最近怎么样？"}]
    }]
)

for block in message.content:
    if block.type == "thinking":
        print(f"推理过程：\n{block.thinking}\n")
    elif block.type == "text":
        print(f"回复：\n{block.text}\n")
```

### 4. 多轮对话的重要说明

多轮函数调用时，必须把完整模型响应（即助手消息）追加到对话历史，以保持推理链连续。将完整的 `response.content` 列表追加到历史，其中包含所有 thinking、text 和 tool_use 内容块。

## 支持的模型

Anthropic SDK 兼容接口当前支持 `MiniMax-M2.1`、`MiniMax-M2.1-lightning` 和 `MiniMax-M2`：

| 模型 | 说明 |
| --- | --- |
| MiniMax-M2.1 | 多语言编程能力强，输出速度约 60 token/秒 |
| MiniMax-M2.1-lightning | 速度更快、更灵敏，约 100 token/秒 |
| MiniMax-M2 | 智能体能力和高级推理 |

其他模型请使用标准 MiniMax API。接口支持范围可能随服务更新而变化。

## 兼容性

### 支持的参数

| 参数 | 支持情况 | 说明 |
| --- | --- | --- |
| `model` | 完全支持 | 支持上述 MiniMax 模型 |
| `messages` | 部分支持 | 支持文本与工具调用；不支持图片或文档输入 |
| `max_tokens` | 完全支持 | 生成令牌上限 |
| `stream` | 完全支持 | 流式响应 |
| `system` | 完全支持 | 系统提示词 |
| `temperature` | 完全支持 | 范围为 `(0.0, 1.0]`，建议值为 1 |
| `tool_choice` | 完全支持 | 工具选择策略 |
| `tools` | 完全支持 | 工具定义 |
| `top_p` | 完全支持 | 核采样参数 |
| `metadata` | 完全支持 | 元数据 |
| `thinking` | 完全支持 | 推理内容 |
| `top_k`、`stop_sequences`、`service_tier`、`mcp_servers`、`context_management`、`container` | 忽略 | 当前接口忽略这些参数 |

### 消息内容类型

| 类型 | 支持情况 | 说明 |
| --- | --- | --- |
| `type="text"` | 完全支持 | 文本消息 |
| `type="tool_use"` | 完全支持 | 工具调用 |
| `type="tool_result"` | 完全支持 | 工具结果 |
| `type="thinking"` | 完全支持 | 推理内容 |
| `type="image"` | 不支持 | 暂不支持图片输入 |
| `type="document"` | 不支持 | 暂不支持文档输入 |

## 流式响应

流式调用会以 `thinking_delta` 和 `text_delta` 增量返回推理内容和文本。应分别处理并累积增量，不能在多轮对话中丢弃 thinking 内容。

## 工具调用与交错思考

要了解 M2.1 工具调用和交错思考的实现方式，请参阅 MiniMax 的[工具调用指南](https://platform.minimax.io/docs/guides/text-m2-function-call)。

## 注意事项

1. Anthropic API 兼容接口当前只支持 `MiniMax-M2.1`、`MiniMax-M2.1-lightning` 和 `MiniMax-M2`。
2. `temperature` 范围为 `(0.0, 1.0]`，超出范围会报错。
3. `top_k`、`stop_sequences`、`service_tier`、`mcp_servers`、`context_management` 和 `container` 等部分 Anthropic 参数会被忽略。
4. 当前不支持图片和文档输入。
